‘Innovations’ in LATEX

The LATEX kernel is a pathway to many abilities some consider to be unnatural.

Package horizontaltoc

The motivation was to reproduce the horizontal table of contents (ToC) one would see in many famous older textbooks (e.g. Weinberg). If one adds the horizontaltoc.sty file to the directory of their TEX file and writes \usepackage{horizontaltoc} in the preamble of their document, they will see a horizontal ToC like that below:

Two options exist for the package:

  • The option figures applies the same horizontal format to entries in the list of figures and the list of tables.
  • The option sansserif changes the font of entry headers (chapter or section, depending on the document class) to Sans Serif.
